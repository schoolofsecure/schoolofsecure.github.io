# Landing page design refinement

## Date
2026-07-16

## Goal
Reduce overly playful startup feel while keeping the brand modern. Clear hierarchy for individual vs team audiences without separate colour systems.

## Changes
- **Hero:** single focused message, two primary CTAs (Play Free, For Teams), terminal visual restored
- **Path blocks:** two side-by-side sections (For individuals / For teams) with bullets and path-specific CTAs
- **Removed from landing:** terminal card, Secure tips, Secure figure, blockquote, How it works grid, duplicate feature cards
- **For Teams page:** aligned copy and cleaner layout matching landing tone
- **Style:** dark base, neon accent sparingly, more whitespace, block structure instead of colour coding

## Updates (2026-07-16)
- Shorter bullet copy on landing path blocks
- Team CTA links to `/teams#contact` form (placeholder submit, no backend yet)
- Minimal cookie banner: bottom-right, small text, subtle accept button
