# Iterali angol rebrand – 2. köteg

## Mit csináltunk

11 fájl UI szövegét fordítottuk magyarról természetes angolra, és a CyberMystery/CM brandinget Iterali-ra cseréltük ahol kellett.

## Módosított fájlok

- `src/pages/Aurora.jsx` – BrandLogo, logger import, angol UI
- `src/pages/Profile.jsx` – BrandLogo, angol profil oldal
- `src/pages/Privacy.jsx` – angol adatvédelmi szöveg, Iterali footer
- `src/pages/NotFound.jsx` – angol 404
- `src/components/ErrorBoundary.jsx` – angol hibaüzenetek
- `src/components/Ugy1/ChallengeInput.jsx` – angol alapértelmezések (Check, Correct!, stb.)
- `src/components/Ugy1/NarrativeBlock.jsx` – Case 1, Introduction
- `src/components/Scoring/ScoreDisplay.jsx` – pts
- `src/components/Scoring/PointAnimation.jsx` – pts
- `src/components/Scoring/LevelCompletionSummary.jsx` – Case completed, angol üzenetek
- `src/components/Scoring/RankBadgeAnimation.jsx` – Rank badge alt szöveg

## Megjegyzések

- Útvonalak változatlanok (`/ugy1`, `/aurora`, stb.)
- Ügy → Case a felhasználói felületen
- Aurora JSON tartalom (`/data/aurora.json`) külön fájl, nem ebben a kötegben
