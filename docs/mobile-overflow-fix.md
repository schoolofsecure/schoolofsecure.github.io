# Mobil: levágott szövegek

Két helyen a szöveg kilógott keskeny telefonon (iPhone SE / 390 px).

## Főoldal

A `SHORT ROUNDS · INSTANT FEEDBACK · CALMER DECISIONS` sor most törhet, a pontok paddingje kisebb.

## Aurora belépő

A Sign in / Register / Reset password gombok mobilon egymás alatt, teljes szélességben. Nem lóg ki a Reset password.
