# Auth & Scoring English Translation

User-facing Hungarian strings translated to English in:

- `src/contexts/AuthContext.jsx` — registration, login, password reset, save/delete messages
- `src/contexts/ScoringContext.jsx` — case titles (aurora.json), scoring feedback
- `src/utils/scoring.js` — ranks, achievements, task/level feedback
- `src/utils/sanitize.js` — Firebase error messages

Case titles match `public/data/aurora.json` (e.g. The Encrypted Data Packet, The Mastermind).

No CyberMystery references were found in these files.
