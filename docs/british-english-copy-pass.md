# British English copy pass

Standardised user-facing copy to British English and removed Oxford commas from lists.

## Spelling updates

- `-ize` → `-ise` (analyse, organise, recognise, personalised, authorised, unauthorised, organisational, labelled, fulfil, defence, centred)
- `-or` → `-our` where applicable (defence, unauthorised)
- `toward` → `towards`
- `human-centered` → `human-centred` (brand, blog)
- `UNAUTHORIZED` → `UNAUTHORISED` (landing terminal)
- `CYBER DEFENSE` → `CYBER DEFENCE` (Caesar task)

## Oxford comma removal

Removed serial commas before final `and`/`or` in multi-item lists across pages, learning content, tasks, Privacy, Pricing, Play, Profile, Aurora and `public/data/aurora.json`.
