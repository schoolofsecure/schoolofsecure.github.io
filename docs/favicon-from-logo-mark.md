# Favicon az Iterali logó jeléből

## Mit csináltunk
Favicon a logó **`<i>`** jeléből: kék `<`, fehér `i`, lila/kék `>`.

## Frissítés
Sötét háttér (`#0b121c`) + vastagabb fehér `i`, hogy világos böngészőfülön is látszódjon.

## Fájlok (`public/`)
- `favicon.svg` — elsődleges
- `favicon.ico`, PNG-k, `apple-touch-icon.png`

## Bekötés
`index.html` — `rel="icon"` + `apple-touch-icon`
